# 스피커 EQ 실제 방 확인 — 2026-10-20

설치된 EFX APO(SMSL USB DAC)가 REW 필터를 실제로 적용하는지 방에서 확인했습니다.
`PersonalToolsAecRoomCheck --tones 66,140,400,1000 --level -20`이 사인파를 1.5초씩 스피커로 재생하고
MOTU 입력 1로 녹음해 각 주파수의 협대역 레벨을 잽니다. 반향 제거를 끈 상태에서 EQ 켬 → 끔 → 켬 순서로 측정했고,
끝난 뒤 두 효과를 다시 켰습니다.

| 주파수 | EQ 켬 (1회/2회) | EQ 끔 | 변화 | 필터 설정 |
| --- | --- | --- | --- | --- |
| 66 Hz | −27.2 / −27.7 dB | −17.1 dB | −10.4 dB | L 66 Hz −12 dB Q7.40, R 65 Hz −8.4 dB Q8.00 |
| 140 Hz | −18.4 / −18.5 dB | −6.5 dB | −12.0 dB | L 140 Hz −12 dB Q3.21, R 142 Hz −12 dB Q3.36 |
| 400 Hz | −22.4 / −22.5 dB | −22.5 dB | +0.1 dB | — |
| 1 kHz | −26.8 / −25.4 dB | −25.4 dB | −0.7 dB | — |

- 마이크가 두 스피커를 함께 들으므로 66 Hz는 좌우 감쇠(−12/−8.4 dB)의 중간 값이 나옵니다.
- 모든 톤이 같은 주파수의 바닥 소음보다 25 dB 이상 컸습니다. 1 kHz의 차이는 회차 간 편차(1.4 dB) 안입니다.
- EQ를 끈 상태의 140 Hz가 다른 대역보다 16 dB 이상 커서, 필터가 이 방의 저음 공진을 줄이고 있음을 보여 줍니다.

## 스트림 종류별 (디스코드 확인)

통화 앱이 쓰는 방식으로도 같은 시험을 했습니다(`--raw`: RAW 스트림, `--category Communications`).
두 경우 모두 66 Hz −10.3 dB, 140 Hz −12.0~−12.1 dB로 일반 재생과 같았습니다.
`PersonalToolsAudioTap`(SMSL 루프백과 마이크 동시 녹음)으로 보면 EQ를 켤 때 루프백의 60–72 Hz,
130–150 Hz 대역이 −12.1 dB 내려갑니다. 즉 이 PC의 루프백은 EQ 뒤의 최종 출력이고, EQ는 장치로 가는
모든 재생을 섞은 뒤 적용됩니다. 같은 시점 디스코드는 SMSL(기본·통신 기본 장치)로 공유 모드 출력 중이었습니다.
화면 공유 등으로 다른 사람에게 보내는 앱 소리는 앱별 캡처라 EQ 전 소리입니다(스피커 보정이므로 정상).
