Personal Tools for Windows

Windows로 옮기기로 한 화면을 Windows 11 디자인 언어로 다시 그렸습니다. 창 배경은 Mica, 글꼴은 Segoe UI Variable, 아이콘은 Segoe Fluent Icons를 쓰고, 강조색은 이 PC의 시스템 강조색을 따릅니다. 화면 속 기록, 장치, 창 이름은 모두 예시입니다.

07

창 전환 알림

창을 등록하거나 빈 키를 눌렀을 때 화면 아래 가운데에 1.5초 동안 나타납니다. 볼륨 알림과 같은 위치와 재질을 써서 작업을 가리지 않고, 포커스도 가져가지 않습니다.

신규Windows 알림 센터에는 남기지 않습니다. 등록한 창으로 전환할 때는 알림 없이 바로 전환합니다.

08

사운드

스피커와 마이크를 Windows 설정 카드로 정리합니다. EQ 필터는 가져온 REW 파일 값을 읽기 전용 표로 보여 줍니다. 반향 제거는 NPU(Intel AI Boost)에서 DTLN-AEC 모델로 처리하고, 처리 장치, 스피커 참조, 입력 레벨을 그 아래에 바로 보여 줍니다.

변경NPU가 준비되지 않았거나 오류가 나면 '처리 중'으로 표시하지 않고 원인과 복구 상태를 표시합니다. 설치 전에는 맨 위에 '설치 및 적용' 안내가 나오고 스위치와 가져오기 버튼이 잠깁니다.

10

진단
